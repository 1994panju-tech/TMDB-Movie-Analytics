
🎬 TMDB Movie Analytics

1. 🎬 Project Title
TMDB Movie Analytics
A data analysis project to understand movie performance using movie, genre, cast, crew, and keyword data.
________________________________________
2. 📌 Project Overview
This project analyzes movie data from TMDB.
The main goal is to understand movie performance based on budget, revenue, ratings, genres, cast, crew, and keywords.
The project includes data cleaning, SQL analysis, Pandas analysis, and data visualization.

5. 💡 Top 5 Insights
1. 💰 Budget vs Revenue
High-budget movies can generate high revenue, but a high budget does not always guarantee success.
2. ⭐ Movie Ratings
Vote average helps us understand how much people like a movie.
3. 🎭 Genre Performance
Different genres have different levels of revenue, ratings, and audience interest.
4. 🎬 Cast & Crew
Popular actors and directors can have an impact on movie performance.
5. 🔎 Keywords
Keywords help us understand popular movie topics and audience interests.
________________________________________


6. 🚀 Recommendations
•	Focus on genres with good revenue and ratings.
•	Consider audience interest before investing a high budget.
•	Analyze successful actors and directors.
•	Use popular keywords to understand audience trends.
•	Consider both ratings and vote count when evaluating movies.
